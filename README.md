## 🤝 Best Practices for Contributing

We welcome contributions from beginners and experienced developers. Feel free to fork the repository and submit pull requests.

### Code Standards

1. Follow PEP 8 — Use consistent naming, 4-space indentation, and docstrings
2. One topic per file — Keep scripts focused and independently runnable
3. Add comments — Explain *why*, not just *what*
4. Use virtual environments — Avoid global installs
